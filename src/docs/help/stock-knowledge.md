# A 股短线交易知识库

「A 股短线交易知识库」是股票分析应用内置的一个**知识中心**（路由 `/stock/knowledge`，从「股票分析」页的「🧠 知识中心」进入）。它把 A 股短线交易相关的知识拆成一个个**知识原子**，覆盖基础知识、交易制度、情绪周期、龙头战法、资金流、盘口、游资、案例、统计等 20 个分类。

> 知识库内容持续维护，并**每周自动扩展**一个新主题；数据通过公开 CDN 实时加载，无需刷新站点即可看到最新内容。

## 怎么用

- **筛选**：按「分类」或「标签」缩小范围（标签按热度排序，展示前 40 个）。
- **搜索**：输入关键词进行全文搜索（匹配标题、摘要、正文与标签）。
- **卡片列表**：每个原子是一张卡片，显示标题、分类与可信度。
- **详情**：点开卡片查看完整正文（Markdown 渲染）、可信度、状态、引用来源与关联原子。
- **知识图谱**：切换到图谱视图，以节点—边展示原子之间的「关联」与「标签共现」关系，点击节点可聚焦其邻居。

## 关于可信度

每条原子都标注了**可信度（0–100）**与**状态**，帮助你判断内容可靠程度：

| 状态 | 含义 |
| --- | --- |
| `verified` | 已有官方规则 / 权威来源支撑 |
| `disputed` | 存在争议或不同流派观点 |
| `unverified` | 尚未充分验证 |
| `experience` | 经验观点，缺乏权威来源（可信度通常 ≤ 45） |

引用来源会随每条原子列出；标注「**【经验观点】**」的内容属于个人经验总结，**仅供学习参考，不构成投资建议**。
