# 给站主打赏

VueChest 是一个**个人维护的免费站点**，没有广告、不强制付费、所有内置应用与市场应用都免费使用。如果你觉得它好用、想支持作者持续维护，可以通过**打赏（赞助）**表达一份心意。本章说明打赏是什么、有哪些方式、以及如何让你的名字出现在"鸣谢墙"。

> 说明：打赏**完全自愿**，不影响任何功能使用。不打赏也完全可以长期使用全部能力。

## 1. 打赏是什么

打赏是一次性的小额支持，与"购买 / 付费会员"不同：

- **不解锁任何功能**：所有应用、市场、账号能力对所有人一视同仁地开放。
- **没有门槛 / 套餐**：金额随心（哪怕一杯奶茶钱也是很大的鼓励）。
- **不是交易**：不提供发票、不承诺交付具体功能（但你的支持会激励作者把站做得更好）。

## 2. 支持的打赏方式

> ⚠️ **当前状态（重要）**：VueChest 目前**没有接入自动支付后端**。下方的收款码由站长配置展示，资金**直接进入站长的个人账户**，平台不经手、不抽成。打赏后请按第 3 节的方式登记，以便登上鸣谢墙。

| 方式         | 说明                                  | 现状           |
| ------------ | ------------------------------------- | -------------- |
| 微信收款码   | 微信"收付款 → 二维码收款"生成的个人码 | 站长配置后展示 |
| 支付宝收款码 | 支付宝"收钱"生成的个人码              | 站长配置后展示 |

- 收款码以**图片**形式展示在「打赏支持」面板中，你用对应 App 扫码即可。
- 为保障你的隐私与资金安全，**请勿**通过其他方式向任何自称"VueChest 客服"的人转账；官方只认站内展示的收款码。

## 3. 打赏后如何登上"鸣谢墙"

打赏是点对点的，站长**无法自动知道是谁打的**。想留名致谢，请：

1. 打赏时在**转账备注**里留下你希望展示的昵称（如"来自小李""VueChest 铁粉"）。
2. 到本站的**交流 / 反馈渠道**（如项目仓库 Issue、站长邮箱，或应用内反馈入口）发一条简短留言，说明"昵称 + 金额 + 渠道"，并**附上转账截图**。
3. 站长核实后，会把你的昵称 + 一句留言 + 打赏日期登记到**鸣谢墙**（见下文）。

> 不想留名？完全 OK。你可以不打备注、不登记，你的支持我们同样记在心里。

## 4. 鸣谢墙

鸣谢墙是「打赏支持」面板里公开展示的名单，按时间倒序排列支持的伙伴：

- 每条记录包含：**昵称（可匿名为"热心网友"）、一句留言（选填）、打赏日期**。
- **不展示**金额、真实姓名、联系方式等敏感信息。
- 由站长手动维护（当前无自动对接），通常会在核实后 1–3 天内更新。

> 如果你希望**移除**已展示的鸣谢记录，联系站长即可随时撤下。

## 5. 安全与边界

- 资金直达站长个人账户，平台不经手，因此**没有"已支付"的官方回执**；以你的转账成功页面为准。
- 警惕冒充：任何在站外私聊你、声称"官方代付 / 代缴"的人都可能是骗子。
- 打赏不可逆，转账前请确认收款码确实来自本站展示页面。
