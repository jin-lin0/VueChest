# VueChest 项目简介

VueChest 是一个**个人 Web "百宝箱"（chest）/工作空间**：它把多个常用的小工具与娱乐应用聚合在同一个站点中，并内置一个**应用市场（Market）**，让你可以像装浏览器插件一样，把自己或他人开发的轻量应用装进 VueChest 里使用。

VueChest 本身是一个运行在浏览器中的单页应用（SPA），无需在本地安装任何客户端，打开网页即可使用。它**完全免费、无广告**，由作者个人维护；如果你觉得好用，欢迎通过底部的"打赏支持"表达一份心意（见 [给站主打赏](./site-donate.md)）。

## VueChest 能做什么

### 1. 内置应用
VueChest 出厂自带一批开箱即用的内置应用（如工具、娱乐、开发助手等），启动后即可在首页直接访问，无需任何安装步骤。

### 2. 应用市场
应用市场是 VueChest 的核心能力之一：

- **浏览与搜索**：按分类（工具 / 娱乐 / 开发 / 游戏 / 生活 / 教育）筛选，或按关键词搜索已上架应用。
- **安装应用**：一键安装市场中的应用，安装后即可从首页或对应路由进入使用，已安装列表会保存在本地。
- **上传应用**：任何登录用户都可以把自己开发的应用打包成 `.js` 文件上传到市场，提交后等待管理员审核即可上架（详见 [如何上传应用到市场](./market-upload.md)）。
- **开发者生态**：应用以标准的 Vite IIFE 包形式发布（详见 [应用包开发规范](./market-spec.md)），普通开发者也能轻松扩展 VueChest 的能力。

### 3. 账号体系
VueChest 提供账号与登录能力：

- 通过**邮箱 + 验证码**即可注册 / 登录，无需记忆复杂密码（详见 [账号与登录](./account.md)）。
- 登录后会获得一个身份令牌（Token），上传应用、发布内容等需要登录态的操作都会自动携带该令牌。
- 登录态默认保存在本地，方便下次访问时自动恢复。

## VueChest 适合谁用

| 用户类型 | 典型场景 |
| --- | --- |
| 普通用户 | 想要一个干净、可自定义的"个人工具箱"，按需安装喜欢的轻量应用 |
| 工具爱好者 | 把零散的小脚本集中到一个站点，统一入口、统一主题 |
| 前端开发者 | 用熟悉的 Vue 生态开发市场应用，发布到 VueChest 与他人共享 |
| 团队 / 个人站长 | 作为可扩展的私人工作空间，沉淀常用功能 |
