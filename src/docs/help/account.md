# 账号与登录

VueChest 使用**邮箱 + 验证码**的方式完成注册与登录，流程简单、无需记忆密码。本章介绍如何注册 / 登录，邮箱验证码的流程，以及登录态的相关说明。

## 注册与登录

1. 打开 VueChest，进入登录 / 注册入口。
2. 输入你的**邮箱地址**。
3. 点击"获取验证码"，系统会向该邮箱发送一封包含验证码的邮件。
4. 查收邮件，将验证码填入页面。
5. 提交后，若邮箱与验证码匹配，即完成登录（首次使用会自动创建账号）。

> 提示：请确保填写的邮箱真实可用，验证码邮件可能被归类到"垃圾邮件"或"推广邮件"，如未收到请稍作等待并检查对应文件夹。

## 邮箱验证码流程

VueChest 的验证码是基于邮箱的一次性凭证，整体流程如下：

1. **请求验证码**：你提交邮箱后，后端会生成一个一次性验证码并发送到该邮箱。
2. **输入验证码**：你在页面上填写收到的验证码。
3. **校验并签发令牌**：后端校验邮箱与验证码是否匹配。校验通过后，会为你签发一个身份令牌（Token）。
4. **保持登录**：前端保存该 Token，后续请求自动携带，维持登录状态。

> 注意：验证码通常有时效限制（如数分钟内有效），过期后需要重新获取。请不要在公共设备上勾选"记住我"类选项以外的敏感操作，使用完毕后建议退出登录。

## 登录态说明

- **令牌（Token）**：登录成功后，后端会返回一个 Token。VueChest 的请求封装（`api.get / post / put / delete`）在发起**需要登录的接口**时，会自动在请求头附加 `Authorization: Bearer <token>`。
- **自动携带**：你无需手动处理鉴权头，调用受保护接口（如上传应用、发布、审核等）时框架会自动带上登录态。
- **本地保存**：登录态会保存在浏览器本地，因此刷新页面或下次访问时通常可以保持登录，无需重复输入验证码。
- **退出登录**：在账号相关入口退出后，本地 Token 会被清除，需要重新走验证码流程登录。

## 接口地址说明

VueChest 的接口基础地址由环境变量 `VITE_API_BASE_URL` 决定：

- 本地开发默认：`http://localhost:3000`
- 生产环境：`https://server.020201.xyz`

所有接口统一返回 `{ success, data }` 结构，便于前端统一处理成功 / 失败。
