# 安装与使用

本章介绍普通用户如何在 VueChest 应用市场中**安装**应用，以及安装后如何**进入和使用**它们。安装过程完全在浏览器本地完成，无需下载桌面客户端。

## 1. 在市场中发现应用

打开 VueChest 的 `/market` 市场页面：

- 可按分类筛选：工具 / 娱乐 / 开发 / 游戏 / 生活 / 教育。
- 可按关键词搜索。
- 点击任意应用，进入应用详情页查看名称、图标、描述、说明等。

> 提示：市场中只展示**已审核通过（已上架）**的应用。待审核状态的应用对其他用户不可见（详见 [审核与发布流程](./market-review.md)）。

## 2. 安装应用

在应用详情页点击"安装"。VueChest 会按如下流程为你安装：

1. **权限确认**：先展示隔离存储、联网域名白名单与完整性校验方式；新增联网域名会单独标出。
2. **并发拉取**：同时获取应用包的二进制内容与应用详情。
3. **完整性校验**：用 Web Crypto 重新计算 SHA-256，与审核版本的服务端记录比对；不一致时立即终止安装。
4. **本地缓存**：校验通过后才将 bundle 缓存到浏览器的 **IndexedDB**，键名前缀为 `market-bundle-`。
5. **运行**：应用包只在 **iframe 沙箱**内执行（见 [沙箱机制](./market-sandbox.md)），不在主页面直接运行。
6. **注册路由**：调用 `registerRoute`，为应用注册一个渲染沙箱容器的路由，路径统一收敛到受控命名空间 `/market-installed/:id`（**不再使用 bundle 自带的 `def.route`**）。

安装完成后，应用就被加入到你的"已安装应用"列表中。

## 3. 安装后如何使用

- **从首页进入**：已安装的应用会出现在 VueChest 首页（或应用入口列表）中，点击即可打开。
- **从路由进入**：应用的实际访问路径统一为 `/market-installed/:id`（`id` 为应用编号）。在沙箱化之后安装的应用均使用此路径；若早期版本安装的应用从首页卡片打开异常，卸载后重新安装即可恢复正常。
- **主题跟随**：市场应用可通过 `window.__APP_THEME__` 跟随站点的深色 / 浅色模式。

## 4. 已安装列表的保存与账号同步

已安装应用的记录（键 `market_installed_apps`）与应用包本体（键前缀 `market-bundle-`）都保存在浏览器的 **IndexedDB** 中（经宿主统一存储层读写，非 localStorage），因此再次打开通常无需重新下载，加载更快。

**登录用户会额外享有跨设备同步**：

- 每次安装 / 卸载后，前端会把已安装应用的 **ID 列表**通过 `PUT /api/auth/installed-apps` 同步到账号。
- 换设备或换浏览器登录后，宿主启动时会对比本地与服务端的列表：
  - 服务端有、本地没有的 → **自动下载并重新安装**（`syncFromServer`，并发下载）。
  - 本地有、服务端没有的（如未登录时安装的）→ **自动补传到服务端**（`syncToServer`）。
- 因此登录状态下，你的已安装应用会在不同设备间保持一致，无需手动重装。

> 说明：同步的是**应用 ID 列表**，应用包本身在新设备上按 ID 重新拉取。**未登录时**安装则仅保存在当前浏览器本地，不会同步；登录后会自动补传。清除本地缓存不影响服务端记录，重新登录即可恢复。

## 5. 卸载 / 重新安装

- 如需移除已安装的应用，可在已安装管理入口（或对应应用菜单）中卸载；该操作会移除对应路由、删除 IndexedDB 中的 `market_installed_apps` 记录与 `market-bundle-<id>` 缓存，并同步到账号。
- 重新安装时，VueChest 会再次拉取并缓存 bundle，注册路由后即可使用。

## 6. 更新、回退与举报

- 自动更新不会静默扩大联网权限；发现新域名时会停止并要求用户确认。
- 每次成功更新或安装历史版本后，宿主会保留一个本地回退点。可在“已安装应用”中一键回退，回退前的当前版本会成为新的回退点。
- 应用详情页可提交安全、隐私、欺诈、内容或版权举报。重复的待处理举报会被拦截，管理员可在应用管理后台记录处理结论并关闭或驳回。
