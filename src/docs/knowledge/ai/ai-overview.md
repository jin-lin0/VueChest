## 建议的系统心智模型

1. 模型负责不确定性推理，不直接获得执行权。
2. Harness / 运行时负责状态、工具、权限、预算、观测和恢复。
3. RAG 与工具提供外部事实，但返回内容仍是不可信输入。
4. 评测必须覆盖最终结果、执行轨迹、延迟、成本与安全。
