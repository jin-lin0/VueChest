# 知识库文章模板（复制改名后使用）

> 用途：新增知识文档时复制本文件，重命名为 `xxx.md`，放到对应一级目录
> （`frontend/` `ai/` `backend/` `interview/` 之一，决定顶层目录），**无需改动 `knowledge/index.ts`**。
> 顶部用 frontmatter 声明分组即可自动注册：
>
>     ---
>     group: 所属二级分组名   # 同 category 内唯一，决定左侧子菜单归属
>     order: 1                # 可选，仅控制同一分组内顺序，越小越靠前
>     ---
>
> 标题自动取正文首个 `# H1`（下面照常写 `# 标题`）。文件名即文档 id（**不要带 `kb-` 前缀**，Tab 由所属注册表推导）。

写作约定（与现有文档保持一致）：

- 中文、务实、给代码不给空话；每段示例标注「什么时候用」。
- 代码块必须带语言标签（`js` / `ts` / `vue` / `python` / `bash` / `json` / `text`）。
- 结尾必须有「参考来源」段，补权威出处链接（目前是质量打磨重点）。
- 标题层级用 `## 一、二、…`，避免和已有文档结构冲突。
- 不臆造版本号 / 数据；有版本依赖时注明「基于 X 版本」并给官方文档链接供查证。
