# 如何上传应用到市场

本指南面向**普通用户**，带你一步步把自己（或他人）开发的市场应用上传到 VueChest 应用市场。上传操作需要先登录（参见 [账号与登录](./account.md)）。

> 提示：上传之前，请确保你已经准备好一个符合规范的 `.js` 应用包。如果你就是开发者，请先阅读 [应用包开发规范](./market-spec.md)；如果你只是代为上传，请向开发者索取正确的 `.js` 文件。

## 一句话结论：上传时需要你填的很少

VueChest 的上传表单**非常精简**。绝大多数应用信息（名称、图标、简介、版本）都**不需要你手动填写**——它们会在你选中 `.js` 文件后，由系统从应用包内部的 `meta` 字段**自动解析并回填**。你真正需要操作的只有：**选择文件**、**选择分类**、（可选）**写说明文档**。

## 必填 / 选填一览

| 项目 | 来源 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| **应用包文件（.js）** | 你选择 / 拖拽 | **必填** | 仅接受 `.js`，且大小 **≤ 10MB** |
| **分类** | 你在下拉框选择 | **必填** | 6 选 1，默认已选中"工具" |
| 说明文档（readme） | 你填写 | 选填 | Markdown 文本，可留空 |
| 应用名称 `name` | 应用包 `meta` 自动解析 | 由包决定（**包内必填**） | 表单不提供输入框 |
| 应用图标 `icon` | 应用包 `meta` 自动解析 | 由包决定（**包内必填**） | 表单不提供输入框 |
| 应用简介 `description` | 应用包 `meta` 自动解析 | 由包决定（可缺省） | 缺省时按空串处理 |
| 版本号 `version` | 应用包 `meta` 自动解析 | 由包决定（可缺省） | 缺省时回退为 `1.0.0` |
| 作者 `author` | 服务端自动填充 | 自动 | 取你的登录用户名，无需填写 |

> 关键点：**名称、图标、简介、版本不在页面上填**，而是写在应用包里（`meta` 字段）。因此"上传时的必填内容"对开发者来说其实是**应用包内 `meta.name` 与 `meta.icon` 必须存在**（服务端会校验，缺失会被拒绝）；对上传者来说，页面上必须做的只有"选对文件"和"选好分类"。

## 上传步骤

### 第 1 步：进入上传页面
打开 VueChest 的 `/market` 市场页面，找到并点击"上传"入口，进入 `/market/upload` 上传页面。

> 注意：上传页面需要登录态。如果未登录，页面会引导你先完成登录 / 注册。

### 第 2 步：选择应用包文件
点击文件区域，或直接把 `.js` 文件**拖拽**到虚线框内。

- 仅接受 **`.js`** 文件（文件选择框限制为 `accept=".js"`）。
- 文件大小不得超过 **10MB**（`10 * 1024 * 1024` 字节）。超出会立即提示"应用包不能超过 10MB"并拒绝。
- 应用包应当是**由 Vite 构建的 IIFE 格式市场应用包**（详见 [应用包开发规范](./market-spec.md)）。

选中文件后，系统会立即读取其文本内容并尝试解析：

- **解析成功**：页面会弹出一张"应用信息"卡片，展示从 `meta` 中解析出的图标、名称、版本、简介，供你核对。
- **解析失败**：提示"**无法解析应用包，请确认文件是有效的市场应用**"，此时无法继续提交，请检查你的 `.js` 是否符合规范。

> 说明：名称 / 图标 / 版本 / 简介都来自这张卡片（即应用包 `meta`），**页面不提供修改入口**。如需改动，请在应用包里改好 `meta` 后重新构建、重新选择文件。

### 第 3 步：选择分类
从下列 6 个分类中选择**一个**最符合你应用的类别（默认已选中"工具"，单选）：

- 工具
- 娱乐
- 开发
- 游戏
- 生活
- 教育

### 第 4 步：填写说明文档（选填）
页面提供一个 Markdown 格式的文本框（placeholder 为"使用 Markdown 格式编写应用说明..."），可在此填写应用的使用说明、功能介绍等。此项为**选填**，可留空。

> 说明：当前应用详情页的 readme 以**纯文本**展示，尚未渲染 Markdown。复杂排版建议在应用内自行说明（详见 [注意事项](./market-notes.md)）。

### 第 5 步：提交并等待审核
确认信息无误后点击"发布到市场"。系统会依次执行：

1. 向服务端申请**预签名地址**，把 `.js` 文件**直传到对象存储（R2）**。
2. 完成上传校验（服务端会**再次核对文件大小 ≤ 10MB**）。
3. 创建应用记录（携带解析出的 `meta` 信息与你选择的分类 / readme）。

- 若解析或提交失败，页面会给出对应的错误提示。
- 若成功，页面会显示"**发布成功！…… 等待管理员审核**"，并提供"前往市场""继续上传"两个按钮。

这意味着你的应用已进入**待审核（pending）**状态，尚不会立即出现在市场中。

## 上传之后

- 提交成功后，应用处于**待审核**状态，**并不会立即可见**。
- 需要等待管理员在后台审核通过（参见 [审核与发布流程](./market-review.md)），应用才会正式上架，其他用户才能在市场中看到并安装。
- 若审核被拒（rejected），应用不会上架；可修正后重新上传。

## 常见上传失败原因

- 选择了非 `.js` 文件 → 前端文件选择框（`accept=".js"`）拦截，无法选中。
- 文件超过 10MB → 前端立即拦截；即便绕过，服务端预签名 / 完成 / 创建三个环节也会再次拒绝。
- 应用包 `meta` 无法被解析 → 提示"无法解析应用包"，多因未正确导出 `default.{component, route, meta}` 或未暴露 `window.MarketApp`。
- 应用包缺少 `meta.name` 或 `meta.icon` → 服务端返回"名称、图标和应用文件不能为空"。
- 把 Vue 打进了包里（未外部化）→ 与原站 Vue 实例冲突，可能无法正常运行（详见 [注意事项](./market-notes.md)）。
- 未登录 → 上传页需要登录态。
