# 如何上传应用到市场

本指南面向**普通用户**，带你一步步把自己（或他人）开发的市场应用上传到 VueChest 应用市场。上传操作需要先登录（参见 [账号与登录](./account.md)）。

> 提示：上传之前，请确保你已经准备好一个符合规范的 `.js` 应用包。如果你就是开发者，请先阅读 [应用包开发规范](./market-spec.md)；如果你只是代为上传，请向开发者索取正确的 `.js` 文件。

## 上传步骤

### 第 1 步：进入上传页面
打开 VueChest 的 `/market` 市场页面，找到并点击"上传"入口，进入 `/market/upload` 上传页面。

> 注意：上传页面需要登录态。如果未登录，页面会引导你先完成登录 / 注册。

### 第 2 步：选择分类
从下列 6 个分类中选择**一个**最符合你应用的类别：

- 工具
- 娱乐
- 开发
- 游戏
- 生活
- 教育

### 第 3 步：填写应用信息
根据页面提示填写应用的基本信息（如名称、图标、简介、版本等）。这些信息将展示在应用市场的列表与详情页中。

### 第 4 步：选择应用包
点击文件选择框，选择你的应用包文件。

- 仅接受 **`.js`** 文件（文件选择框的限制为 `accept=".js"`）。
- 应用包应当是**由 Vite 构建的 IIFE 格式市场应用包**。
- 若文件过大或非 `.js` 文件，前端会直接拦截：文件大小不得超过 **10MB**（即 `10 * 1024 * 1024` 字节）。

> 注意：10MB 是**前端约束**——超大文件或非 `.js` 文件会被前端拦截，无法进入提交流程。

### 第 5 步：填写说明文档（选填）
页面提供一个 Markdown 格式的文本框（placeholder 为"使用 Markdown 格式编写应用说明..."），可在此填写应用的使用说明、功能介绍等。此项为**选填**。

> 说明：当前应用详情页的 readme 以**纯文本**展示，尚未渲染 Markdown。复杂排版建议在应用内自行说明（详见 [注意事项](./market-notes.md)）。

### 第 6 步：提交并等待审核
确认信息无误后点击提交。系统会先校验应用包是否可被解析：

- 若包无法解析，会提示"**无法解析应用包，请确认文件是有效的市场应用**"，请检查你的 `.js` 文件是否符合规范。
- 若校验通过并提交成功，页面会提示："**发布成功！…… 等待管理员审核**"。

这意味着你的应用已进入**待审核**状态，尚不会立即出现在市场中。

## 上传之后

- 提交成功后，应用处于**待审核**状态，**并不会立即可见**。
- 需要等待管理员在后台审核通过（参见 [审核与发布流程](./market-review.md)），应用才会正式上架，其他用户才能在市场中看到并安装。
- 审核通过后的上架、更新等事宜，请参阅 [审核与发布流程](./market-review.md)。

## 常见上传失败原因

- 选择了非 `.js` 文件 → 前端拦截，无法选择/提交。
- 文件超过 10MB → 前端拦截。
- 应用包没有正确导出 `default.{component, route, meta}` → 提示"无法解析应用包"。
- 包里把 Vue 打进去了（未外部化）→ 与原站 Vue 实例冲突，可能无法正常使用（详见 [注意事项](./market-notes.md)）。

更多疑问见 [常见问题 FAQ](./faq.md)。
