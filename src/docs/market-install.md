# 安装与使用

本章介绍普通用户如何在 VueChest 应用市场中**安装**应用，以及安装后如何**进入和使用**它们。安装过程完全在浏览器本地完成，无需下载桌面客户端。

## 1. 在市场中发现应用

打开 VueChest 的 `/market` 市场页面：

- 可按分类筛选：工具 / 娱乐 / 开发 / 游戏 / 生活 / 教育。
- 可按关键词搜索。
- 点击任意应用，进入应用详情页查看名称、图标、描述、说明等。

> 提示：市场中只展示**已审核通过（已上架）**的应用。待审核状态的应用对其他用户不可见（详见 [审核与发布流程](./market-review.md)）。

## 2. 安装应用

在应用详情页点击"安装"。VueChest 会按如下流程为你安装：

1. **并发拉取**：同时获取应用包的文本内容（bundle）与应用详情。
2. **本地缓存**：将 bundle 缓存到浏览器的 **IndexedDB**，键名前缀为 `market-bundle-`。
3. **解析**：调用 `loadMarketApp(code)` 解析应用包，读取全局 `window.MarketApp`。
4. **注册路由**：调用 `registerRoute`，将应用定义中的 `def.component` 动态注册为路由，访问路径取 `def.route`（如 `/m/counter`）。

安装完成后，应用就被加入到你的"已安装应用"列表中。

## 3. 安装后如何使用

- **从首页进入**：已安装的应用会出现在 VueChest 首页（或应用入口列表）中，点击即可打开。
- **从路由进入**：你也可以直接访问应用在注册时对应的路径（即 `def.route`，例如 `/m/counter`）来使用它。
- **主题跟随**：市场应用可通过 `window.__APP_THEME__` 跟随站点的深色 / 浅色模式。

## 4. 已安装列表的保存

已安装应用的列表保存在浏览器的 **`localStorage['market_installed_apps']`** 中：

- 这意味着"已安装"是**按浏览器 / 设备**本地保存的，切换浏览器或清除本地数据后，已安装列表会丢失，需要重新安装。
- 应用包本体缓存于 IndexedDB，因此再次打开通常无需重新下载，加载更快。

> 注意：已安装状态**不与账号云端同步**。换设备、清缓存或换浏览器时，需重新在市场里安装一次。

## 5. 卸载 / 重新安装

- 如需移除已安装的应用，可在已安装管理入口（或对应应用菜单）中卸载；该操作会更新 `localStorage['market_installed_apps']`。
- 重新安装时，VueChest 会再次拉取并缓存 bundle，注册路由后即可使用。
